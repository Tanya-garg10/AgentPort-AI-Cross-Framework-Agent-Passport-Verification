# AgentPort AI Frontend

The frontend for AgentPort AI is built with React 19, TypeScript, Vite, and Tailwind CSS.
The production web application source code is maintained in `src/` with live hot-reloading:

- `src/App.tsx`: Main application shell with dark developer UI and tabbed navigation.
- `src/components/PassportCard.tsx`: Holographic Agent Passport with embedded framework visas.
- `src/components/FrameworkExplorer.tsx`: Four independent framework adapters with live code/artifact export.
- `src/components/PortabilityMatrix.tsx`: Deep comparison of preserved vs. transformed capabilities.
- `src/components/VerificationLab.tsx`: Live deterministic verification timeline and failure simulator.
- `src/components/SecuritySimulator.tsx`: Deterministic policy evaluator (ALLOW, REQUIRE APPROVAL, BLOCK).
- `src/components/EvidenceViewer.tsx`: Downloadable Markdown and JSON cryptographic evidence reports.
- `src/components/ScoreBreakdown.tsx`: Real-time 575-point challenge scoring breakdown.
- `src/engine/`: Deterministic client-side verification and security simulation engine.
